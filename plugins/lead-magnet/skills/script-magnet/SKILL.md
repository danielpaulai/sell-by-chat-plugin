# Script magnet

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`.

Build spec:
1. One moment, not a library: the exact conversation where the splinter hurts (the dead-lead follow-up, the price question, the no-show).
2. 3 to 5 scripts maximum, each: the situation in one line, the script word for word, one pro-tip line on delivery. Sorted by situation so they can find theirs in five seconds.
3. Scripts sound like a person, not a sales manual: contractions, short lines, one question per message.
4. Mark the one variable to personalize per script in [BRACKETS]; everything else is send-as-is.
5. End with the pointer, and note the natural next magnet (the moment right after this one).

Anti-patterns: 20-script dumps, scripts that pitch in message one, corporate phrasing.
