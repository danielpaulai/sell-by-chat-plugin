# Checklist magnet

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`. Warning first: a basic "10 things you already know" checklist is dust. This format only earns its place when the value is the ORDER and the DONE-STATES of a process the user has run many times.

Build spec:
1. One process, start to finish, that completes in one sitting. 8 to 14 items.
2. Every line starts with a verb and ends with a verifiable done-state ("Subject line under 45 characters: __").
3. Include the 2 or 3 "everyone misses this" items marked with a flag - those carry the perceived value and only an operator would know them.
4. One page. If it needs two, split into two magnets.
5. End with the pointer, plus one line: "want this done for you / with you" leading to the next step.

Anti-patterns: knowledge lists, items without done-states, mixed processes on one page.
