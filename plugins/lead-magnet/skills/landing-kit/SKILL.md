# Landing Kit

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`. The visitor arrives from a DM or post already sold; the page confirms.

1. **Opt-in page copy** (final copy, nothing extra): eyebrow (format + audience, caps), headline repeating the post's promise almost word for word, one subhead (what they can do + how long), three named-item bullets, form label "Where should I send it?", first-person outcome button, one under-button trust line, one credibility line only if a real number exists.
2. **Thank-you page**: confirm the sender + subject to look for; then FOUR multiple-choice questions above the fold, answerable in 15 seconds, each answer changing how you would write to that person; a small named incentive for finishing; then the bridge to the offer page with a headline variant per segment.
3. **Delivery email**: under 120 words, link early, two lines selling what is inside (name the best part), "start on [X]", what arrives next, a reply prompt, P.S. finish the survey.
4. Rules: one field (email only), no menu, no footer links, magnet cover shown not a stock photo, headline matches the post. Six rules total, name any the user's platform breaks.
5. Ship: the copy block for Kit/Beehiiv/GHL paste-in, AND (offer it) a self-contained branded HTML page pair via /lead-magnet:build-the-file for platforms that take custom HTML. Include the go-live test: a real address, on a phone, end to end.
