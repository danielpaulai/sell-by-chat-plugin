# Counter Scripts

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`. Write, in the user's voice, sounding like a person typing on a phone (short lines, no formatting):

1. THE DELIVERY (under 60 words): names what they commented on, asks "where do I send it?" so the win arrives by email, ends with one small easy question that starts a conversation. Three closing-question variants, recommend one.
2. THEY SAY THANKS: warm, short, zero pitch.
3. A REAL QUESTION: answer it fully and generously; this person becomes the client.
4. DAY-3 SILENCE: one new small thing, no "did you read it", no offer, no guilt.

Plus: the connection-request variant for platforms that need one, the rule that a pitch belongs only where they ask "what do you do?", and a 5-second triage rule (standard send / personal note / real conversation this week). Never pitch in message one.
