# Tiny Win (the master skill)

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md` first. Then run the five moves in order, checking in after each. If BUSINESS-BRAIN.md or similar context exists in the workspace, read it and pre-fill; otherwise ask only for: who they help, the offer the magnet should feed, and one asset they already own that clients love.

0. **Research first when it helps** - if the user wants evidence instead of brainstorming (or their context is thin), run /lead-magnet:splinter-scout (market language + working formats via Apify) and/or /lead-magnet:magnet-radar (competitor giveaways on the Magnet Map) and build the board from findings.
1. **Pick it** - propose 3 problems x 3 splinters from their context, in the client's spoken words. Ask them to pick one (recommend one). Confirm the exact person.
2. **Pack it** - pick the format via `${CLAUDE_PLUGIN_ROOT}/references/method.md` rules; prefer a format skill if one fits (prompt-magnet, template-magnet, script-magnet, scorecard-magnet, checklist-magnet) and follow its build spec. Write the fix in 5 steps max. Run the posted-and-lost-nothing test out loud.
3. **Name it** - 5 name candidates (mix their keywords with thing-words), recommend one, then the headline via the recipe. Run the swap test.
4. **Post it** - write the hand-raiser (platform-neutral), one keyword, and confirm delivery is by email into their newsletter or waitlist.
5. **Point it** - write the three-part magnet copy in full (Problem / Fix / Pointer) plus the pointer matched to their real next step.

Then the follow-through, without being asked:
- The Seven-Day Echo: five finished emails (subject + body, phone-sized) per the ratio in method.md, invoking `seven-day-echo` rules.
- The Counter Scripts: four DM replies per `counter-scripts`.
- Score it: Tiny 2X, Named 2X, Instant, Posted, Pointed (g/y/r, max 14). One fix line per non-green. If 12+, tell them to post inside 24 hours. Posted beats perfect.

Then SHIP IT: run /lead-magnet:build-the-file to produce the actual branded deliverable (printable HTML/PDF, or a working tool for calculator and scorecard formats), and offer /lead-magnet:landing-kit for the capture layer. Deliver everything as one clean markdown pack plus the real files. Voice rules from method.md are binding.

## Build Room handoff
If the user arrives with a Tiny Win Pack from the Lead Magnet Build Room (pasted text or a downloaded file), do NOT redo the five moves. Read the pack, confirm the decisions in one line, and go straight to building the finished magnet as a real deliverable: a polished one-page HTML file (their brand colors if known, printable to PDF: Problem / Fix / Pointer laid out properly) via the matching format skill, plus the five emails from seven-day-echo and the DM replies from counter-scripts.
