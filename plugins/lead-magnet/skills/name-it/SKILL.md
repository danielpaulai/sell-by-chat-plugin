# Name it

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`. Process: description + benefit in plain words -> 3 keywords + 3 thing-words (Machine, Script, Reviver, Scorecard, Cheatsheet, Formula, Fixer, Snapshot...) -> 6 mix-and-match candidates -> recommend the one that "sounds like a thing you could hand someone". Then the headline: small number + the thing + concrete outcome + timeframe + (without the pain). Run the swap test (competitor could not run it unchanged) and the believability test (small promise beats big). Never invent numbers; if the headline needs one they do not have, write [NEED: what to count]. Output: the name, the headline, two backup names.
