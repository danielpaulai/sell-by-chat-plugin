# Teardown magnet

Read `${CLAUDE_PLUGIN_ROOT}/references/method.md`.

Build spec:
1. 3 to 5 real examples (posts, pages, emails, profiles) in the niche. Source them with the user, or via Apify (rag-web-browser, platform scrapers) with the user confirming each. Real and attributable only; anonymize if needed but never invent.
2. Two-column anatomy per example: the actual thing on the left, the job each part does on the right ("hook: a quantified loss, then the implication they are blind to it"). The annotation is the product.
3. Every example ends with THE PATTERN in one line, and the full set ends with the meta-pattern across all examples plus a copy-this skeleton the reader can use immediately.
4. One deliberate bad example marked up the same way earns its place: seeing the miss teaches the hit.
5. Ship via /lead-magnet:build-the-file; annotations in accent callouts beside tinted panels.

Anti-patterns: examples without annotations (that is a swipe file, use script-magnet), praising instead of explaining, borrowed teardowns you did not do.
